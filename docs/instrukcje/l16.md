# l16 — Uruchom samoczyszczenie pralki

**Candy BP 49SBL8-S · Co 50 prań**

[Zdjęcie urządzenia](../zdjecia.md#candy)

1. Przed rozpoczęciem możesz [sprawdzić licznik prań](candy-counter.md).
2. Opróżnij bęben. Nie dodawaj detergentu, Calgonu ani środka do czyszczenia pralki.
3. Wybierz BĘBEN CZYSTY (90°C) i uruchom program.
